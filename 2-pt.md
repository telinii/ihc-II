# IHC II — Princípios de Projeto de Interface

> **Tema:** Princípios de Projeto de Interface — IHC

## Interação

- **Interação com o software** = espaço comunicacional humano-computador
- **Interação Humano-Computador (IHC)**
  - Facilitar o diálogo usuário-máquina
  - Molda a tecnologia para se adaptar à humanidade
  - Objetivo: fornecer produtos digitais mais eficientes e acessíveis

## Lado humano

- **Influências no uso:** trajetória, aprendizados e experiências de vida
- **Fatores:**
  - Desejos e necessidades dos usuários
  - Habilidades ou limitações físicas
  - Funcionamento do sistema de percepção do usuário
    - Pistas captadas pelo sistema perceptivo para ações
    - Atração/agradabilidade na interação com o computador

## Lado máquina — Hardware + Software

- Sinais elétricos (digitais)
- (Ligado/desligado) — invisíveis
- Processos internos — transmissão de dados em barramentos

## Comunicação (diálogo)

- Explícita, planejada e implementada
- Acontece na interação
- Envolve ciências comportamentais, computação, etc.
- Objetivo: minimizar o custo de interação e tornar a interação mais humana
- Diminuir o esforço físico e mental no uso
